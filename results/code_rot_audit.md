# Code-rot audit (pre-cleanup)

This inventory was completed before deletion. It covers the 13 Python files, all tracked scripts and result generators, 94 result files present at audit time, ignored caches, command-line options, imports, top-level definitions, generated figures, demo assets, and reproducibility records. The audit used `git ls-files`, `find`, `rg`, SHA-256 duplicate detection, and a Python AST import/symbol scan. No additional lint tool was installed; `ruff` and `pyflakes` were not present.

## Audit conclusion

The repository contains little genuine code rot. Cleanup should be deliberately small: generated Python caches, one obsolete placeholder, three unused imported names, and two unused constants. Scientific source/history and visually reviewed artifacts should remain even when they appear old or large.
